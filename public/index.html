A consultar /api/health

Importante: o site pode chamar esta API diretamente somente se o domínio estiver listado em CORS_ORIGINS. Nunca exponha a sua API_KEY

Início rápido

  1. Leia o QR em POST /api/v1/auth/session e aguarde o estado ready.
  2. Envie os números para a fila e guarde o jobId.
  3. Consulte o progresso e, após concluir, os resultados.

Endpoints

POST/api/v1/auth/session

Estado da sessão e QR code base64.

POST/api/v1/verify/batch

Envia {"numbers":["5511999999999"]} e retorna 202 com jobId.

GET/api/v1/verify/status/:jobId

Estado, contadores e progresso percentual.

GET/api/v1/verify/results/:jobId

Relatório dos números verificados.

Exemplo seguro — backend do seu site

const response = await fetch('https://SUA-API/api/v1/verify/batch', {
  method: 'POST',
  headers: { 'content-type': 'application/json', 'x-api-key': process.env.WHATSAPP_API_KEY },
  body: JSON.stringify({ numbers: ['5511999999999'] })
});
const { jobId } = await response.json();
Use apenas números que tem autorização para consultar e respeite os termos do WhatsApp.
